# v1.0.1

默认只登录时运行；健康时给出可见提示；卸载不再自动改背景。

## 相对 v1.0.0 的变化

1. 安装默认只在登录时检查一次，任务里只有 `AtLogOn` 一个触发器。需要周期检查时显式传 `-CheckEveryMinutes 30`
2. 判定为健康时在控制台打印一行结论，不再只写日志文件
3. `-Check` 打印 `OK` / `DEGRADED` 及关键指标，退出码语义不变
4. 卸载默认只删计划任务并打印安装前快照，不再写回注册表
5. `-RestoreSettings` 按目标状态收尾：非幻灯片删掉 ini，幻灯片从备份还原

## 为什么需要它

`%APPDATA%\Microsoft\Windows\Themes\slideshow.ini` 是幻灯片配置的唯一载体。任何一次「设壁纸」操作（`SystemParametersInfo(SPI_SETDESKWALLPAPER)`）都会把它清空成 0 字节，之后设置里的「幻灯片放映」再也写不进去，桌面退回「图片」或「Windows 聚焦」。

本工具不生成这个文件——里面的 `ImagesRootPIDL` 由 Windows 加密编码，手工造不出来。它只做三件事：安装时备份、登录时检查、损坏时还原。

## 安装

1. 下载 `slideshow-guard-v1.0.1.zip` 并解压到任意目录
2. 确认这台机器的幻灯片本来能用：手动设置一次「幻灯片放映」，等一个间隔，桌面确实换了图
3. 在解压目录打开 PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

不需要管理员权限。所有读写都在当前用户范围内：

| 位置 | 用途 |
|---|---|
| `%LOCALAPPDATA%\slideshow-guard\` | 程序、配置、日志、ini 备份 |
| `%APPDATA%\Microsoft\Windows\Themes\slideshow.ini` | 读取与还原 |
| `HKCU\...\Wallpapers`、`Control Panel\Personalization\Desktop Slideshow` | 背景类型与间隔 |
| 计划任务（当前用户名下） | 登录时触发 |

## 日常命令

```powershell
$g = "$env:LOCALAPPDATA\slideshow-guard\slideshow-guard.ps1"

powershell -ExecutionPolicy Bypass -File $g -Status   # 状态报告
powershell -ExecutionPolicy Bypass -File $g -Check    # 只检测，健康返回 0
powershell -ExecutionPolicy Bypass -File $g -Apply    # 立刻修一次
```

健康时的状态报告：

```

切换间隔       : 1 分钟
slideshow.ini  : 829 字节
上次转码       : 不到 1 分钟前
静默容限       : 10 分钟
ini 备份       : 829 字节
计划任务       : Ready / 最近运行 2026-11-15 22:02:02 (成功)
结论           : OK
```

## 卸载

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
```

默认只删计划任务，打印安装前的配置供手工恢复。不改任何背景设置、不改 `slideshow.ini`。

需要脚本代劳时加 `-RestoreSettings`：恢复为非幻灯片会删除 ini（0 字节空文件会挡住设置里的「幻灯片放映」），恢复为幻灯片会从备份还原 ini。

## 已知限制

- 图库只有 1 张图时，幻灯片状态成立但不会换图
- 还原 ini 后要重启 explorer，登录时会闪一下任务栏；正常开机时 explorer 新启动、直接读到有效 ini，不需要重启
- 依赖 PowerShell 5.1（Windows 10 自带）
- 只针对 Windows 10 验证过（`10.0.19044`）

## 验证过什么

- `rundll32 themeui.dll,OpenThemeAction` 在本机会阻塞不返回，主题文件方案不可用
- PIDL 编码本身可复现（与 Windows 写入的值逐字符一致），但 explorer 不认外部写入的 `BackgroundType`
- 删除 ini 不会自动重建，重启 explorer 后轮播停止
- 0 字节 ini 会把 `BackgroundType` 重置为 0
- 还原备份 ini + 重启 explorer 后，轮播在下一个整分钟恢复

细节见仓库里的 `docs/adr/0001-slideshow-ini-carries-the-config.md`。
